# Agent instructions

Guide for coding agents working in a project made from the **guarded-lending** template (Claude Code loads it through `CLAUDE.md`). Read `README.md` first, and `docs/oracle-guard.md` before changing pricing.

## Commands (npm only)

```bash
npm run foundry:test          # offline; must stay green
npm run foundry:test:testnet  # live testnet feeds
npm run lint                  # next lint + forge fmt --check + prettier (needs make)
npm run next:check-types
npm run next:build
npm run next:dev
```

Deploying: see README "Deploy your own". Use **Foundry below 1.8**: 1.8 sends EIP-1898 block objects the Hedera RPC rejects (`-32602 ... [object Object]`).

## Where things are

- `packages/foundry/contracts/`: `oracle/OracleGuard.sol`, `oracle/sources/*`, `LendingMarket.sol`, `Guardian.sol`
- `packages/foundry/script/Deploy.s.sol`: feed addresses per chain and every parameter
- `packages/foundry/scripts-js/`: `setupMarket.js` (post-deploy HTS/HSS calls)
- `packages/foundry/test/`: `BonzoReplay.t.sol` is the threat model; `mocks/` stand in for HTS (`0x167`) and HSS (`0x16b`)
- `packages/nextjs/components/lending/`, `hooks/lending/`, `utils/lending/`: the dashboard
- `packages/nextjs/contracts/deployedContracts.ts`: generated by `generateTsAbis.js`, never hand-edit

## Invariants

1. Price-dependent market actions (borrow, withdraw collateral, liquidate) get their price from `_guardedPrice()`. `GUARD.lastPrice()` is for display only.
2. Supplying, adding collateral and repaying never need a price and must work while the breaker is tripped.
3. `OracleGuard.poke()` and `Guardian.tick()` never revert.
4. No admin keys, pause switches or price overrides.
5. Quorum stays a strict majority of sources.
6. Units: HBAR is tinybars (8 decimals) inside the EVM and weibars (18) over JSON-RPC; prices are 18 decimals; USDC has 6.
7. No HTS/HSS calls in `Deploy.s.sol`; they belong in `setupMarket.js`.
8. A contract creating an HTS token can only name itself as auto-renew account (HTS returns 326 otherwise).
9. Scheduling calls `0x16b` directly, never via DELEGATECALL, and needs ~1.4M gas.

## Changing things

- **New price source:** implement `IPriceSource` (revert on data the provider flags; leave staleness to the guard), wire it in `Deploy.s.sol`, add a `useSource` slot in `hooks/lending/useOracleGuard.ts`.
- **Pricing or guard changes:** `BonzoReplay.t.sol` must keep all four outcomes, and so must the fuzz test in `OracleGuard.t.sol`.
- **Frontend:** use the scaffold hooks (`useScaffoldReadContract` / `useScaffoldWriteContract`) with `...POLLED`, HTS tokens through `useHtsToken`, and history from the mirror node (`utils/lending/mirrorNode.ts`). Format with `npx eslint --fix`, not the prettier CLI.

## Never

Commit `.env*`, private keys, `deployments/` or `broadcast/`. Put the Pyth API key in a `NEXT_PUBLIC_` variable.
